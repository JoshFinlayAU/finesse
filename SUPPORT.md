# Getting help with Finesse

Finesse is published by Athena Networks.

- **Bugs and feature requests:** open an issue at https://github.com/JoshFinlayAU/finesse/issues. Please include your Apple TV model, tvOS version, Jellyfin server version, and what you were playing.
- **Email:** support@athenanetworks.com.au
- **Phone:** 1300 409 252, from within Australia
- **Post:** Athena Networks, Parcel Locker 10303 80643, 139 Brisbane Road, Booval QLD 4304, Australia

Finesse needs a Jellyfin server that you run or have access to. Questions about the server itself are best asked in Jellyfin's own community: https://jellyfin.org/contact
